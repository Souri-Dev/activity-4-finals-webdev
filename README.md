# Symfony HomeController Activity Instructions

## Overview

This activity demonstrates a simple Symfony controller (`HomeController`) that responds to the root URL (`/`).

## Instructions

1. **Run the Symfony server** and visit the home page.
2. **Review the controller code.**
3. **Identify any issues or bugs in the code.**
4. **Fix the issues you found and make any improvements or fixes you find necessary.**
5. **Test your changes** by reloading the home page and ensuring the controller behaves as expected.

## Learning Goals

- Understand how Symfony controllers handle requests and responses.
- Practice identifying unreachable code and subtle bugs.
- Gain experience debugging and improving PHP/Symfony code.

| Criteria                                 | Points |

| Successfully fixes all identified issues | 15     |
